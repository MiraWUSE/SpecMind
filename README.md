# SpecMind

**SpecMind** — современное десктопное приложение для мониторинга и анализа характеристик компьютера. Сканирует оборудование, отображает данные в реальном времени и экспортирует подробные отчёты.

> ⚠️ **Статус:** Приложение находится в активной разработке. Некоторые функции могут работать нестабильно.

---

## Возможности

### Мониторинг в реальном времени
- Графики загрузки CPU и GPU с обновлением каждую секунду
- Интерактивные tooltip при наведении на точки графика
- Визуальные индикаторы статуса (норма / повышена / критично)
- Отслеживание температур компонентов

### Анализ оборудования
- **Процессор:** название, ядра, потоки, частоты, архитектура, сокет, кэш L1/L2/L3
- **Видеокарта:** VRAM, CUDA cores, TDP, PCIe версия, драйвер, Device ID
- **Оперативная память:** объём, тип (DDR4/DDR5), частота, form factor, слоты
- **Накопители:** тип (NVMe/SSD/HDD), интерфейс, объём, серийный номер
- **Материнская плата:** производитель, модель, BIOS, чипсет

### 📄 Экспорт отчётов
Поддержка 4 форматов экспорта с выбором места сохранения:
- **TXT** — красивый текстовый отчёт с ASCII-оформлением
- **JSON** — структурированные данные для программ
- **CSV** — таблица для Excel
- **HTML** — стильная веб-страница с тёмной темой

### Система тем оформления
Мгновенное переключение без перезагрузки
- **Night Owl** — тёмная тема по умолчанию
- **Daylight** — светлая тема
- **Cyberpunk** — неоновая тема
- **Случайная тема** — генератор уникальных цветовых схем

### Настройки
- Темы и цвета
- Язык интерфейса (в разработке)
- Общие настройки (в разработке)
- Уведомления (в разработке)
- Автозапуск (в разработке)

### Визуальные компоненты
- Круговые индикаторы для метрик
- Линейные графики с градиентной заливкой
- Карточки с иконками и цветовой индикацией
- Адаптивный интерфейс с прокруткой
