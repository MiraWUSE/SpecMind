# Демонстрация SpecMind

[Открыть презентацию PowerPoint](SpecMind-demo.pptx)

10 слайдов на русском для выступления перед пользователями на 5–7 минут. Презентация охватывает обзор компьютера, подробные характеристики, мониторинг CPU/GPU, экспорт TXT/JSON/CSV/HTML, локальный AI и темы оформления.

Текст на слайдах редактируется в PowerPoint. Презентация описывает текущую реализацию на 19 сентября 2026 года. Источники указаны в заметках соответствующих слайдов.
